## Projects

### [CarInfo](https://carinfo-client.vercel.app) · [source](https://github.com/alysibak/carinfo)
`React` `TypeScript` `Express` `PostgreSQL`

A vehicle research platform built over a 28,000-car EPA dataset enriched with NHTSA safety data. Solo build across 15 routes, the schema, the backend, and deployment.

Every field carries a provenance label — verified, curated, or estimated. I added that system after an import bug misclassified 419 plug-in hybrids and threw ownership-cost estimates off by 60 to 70 percent. The fix was cheap; knowing which numbers to trust was the actual problem.

### [Mizan](https://mizan-sandy-eight.vercel.app) · [source](https://github.com/alysibak/mizan)
`Next.js 15` `TypeScript` `Drizzle` `PostgreSQL`

A personal wealth and asset tracker with a rules-based calculation engine. Solo build, structured as server components, user-scoped REST handlers, and a dependency-free calculation core covered by Vitest.

Keeping the calculation layer free of I/O means the rules can be tested in isolation and reasoned about without a database in the loop.

### [TimeVault](https://timevault-web.onrender.com) · [source](https://github.com/alysibak/TimeVault)
`Flask` `Python` `PostgreSQL` `JWT` `Recharts`

A First World War courts-martial records platform holding 57,000 records, built by an 8-person agile team. I owned the REST API layer serving three machine learning models, along with JWT role-based access control, the audit log, and QA.

### [Bystander](https://devpost.com/software/bystander) · [source](https://github.com/hackcanada2026-aaaa/bystander)
`React` `Node` `Express` `Google Gemini`

Won **Best Use of Presage Technologies at HackCanada 2026, out of 800 participants**. Four people, 36 hours. I built the React frontend, the Node and Express backend, and the Gemini integration.
